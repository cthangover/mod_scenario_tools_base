# シナリオツールベース — エディター向けのシナリオファイル

`scenario_tools_base` はシナリオファイルを読み書きするエディターが共有するライブラリです。ウィンドウは追加せず、必要とするエディターと一緒に入ります。

## 利用しているもの

シナリオエディター、シーンエディター、インタラクティブエディターとライトエディター、RPG マップエディター。

## 提供するもの

- **`ScenarioFileService`** — 全 MOD の `.scenario` ファイルを見つけ（`ScanScenarioFiles`）、読み書きし（フォルダー MOD のみ）、ヘッダー（シーン、優先度）を解析し、参照（シーン切り替え、ローカライズキー、クエスト、背景）を取り出し、シーン用の新しいシナリオを作り（`CreateForScene`）、シーングラフを組み立てます（`BuildSceneGraph`、シナリオエディターのグラフのデータ）。
- **`ScenarioSyntaxService`** — エディターのテキスト欄でのシナリオ言語のハイライト（RPG マップエディターはイベントスクリプトに使います）とコマンド行の分割。インタラクティブエディターはこれでどのシナリオがインタラクティブを追加するかを探し、ライトエディターはファイルサービスで `light_set` 行を読み書きします。

言語そのものはダイアログエンジン（`dialog_base`）から来ます。中立的なファイル・シーンのサービスは `tools_base` に残っているので、シナリオを扱わないツールがダイアログエンジンを引き込むことはありません。

## 依存関係

`tools_base`、`dialog_base`。
