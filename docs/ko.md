# 시나리오 도구 기반 — 에디터용 시나리오 파일

`scenario_tools_base`는 시나리오 파일을 읽거나 쓰는 에디터들이 함께 쓰는 라이브러리입니다. 창을 추가하지 않으며 필요한 에디터와 함께 설치됩니다.

## 사용하는 곳

시나리오 에디터, 장면 에디터, 상호작용 에디터와 조명 에디터, RPG 맵 에디터.

## 제공하는 것

- **`ScenarioFileService`** — 모든 모드의 `.scenario` 파일을 찾고(`ScanScenarioFiles`), 읽고 쓰며(폴더 모드만), 헤더(장면, 우선순위)를 해석하고, 참조(장면 전환, 현지화 키, 퀘스트, 배경)를 뽑아내고, 장면용 새 시나리오를 만들고(`CreateForScene`), 장면 그래프를 만듭니다(`BuildSceneGraph`, 시나리오 에디터 그래프의 데이터).
- **`ScenarioSyntaxService`** — 에디터 텍스트 칸의 시나리오 언어 강조(RPG 맵 에디터는 이벤트 스크립트에 사용)와 명령 줄 분해. 상호작용 에디터는 이것으로 어떤 시나리오가 상호작용 오브젝트를 추가하는지 찾고, 조명 에디터는 파일 서비스로 `light_set` 줄을 읽고 다시 씁니다.

언어 자체는 대화 엔진(`dialog_base`)에서 옵니다. 중립적인 파일·장면 서비스는 `tools_base`에 남아 있어, 시나리오를 다루지 않는 도구가 대화 엔진까지 끌어오지 않습니다.

## 의존성

`tools_base`, `dialog_base`.
