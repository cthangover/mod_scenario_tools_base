# Основа сценарных инструментов — файлы сценариев для редакторов

`scenario_tools_base` — библиотека, общая для редакторов, которые читают или пишут файлы сценариев. Окон она не добавляет и приходит вместе с редакторами, которым нужна.

## Кто её использует

Редактор сценариев, редактор сцен, редакторы интерактивов и освещения, редактор RPG-карт.

## Что она даёт

- **`ScenarioFileService`** — находит файлы `.scenario` всех модов (`ScanScenarioFiles`), читает и пишет их (только моды-папки), разбирает заголовок (сцена, приоритет), извлекает ссылки (переходы между сценами, ключи локализации, квесты, фоны), создаёт новый сценарий для сцены (`CreateForScene`) и строит граф сцен (`BuildSceneGraph` — данные для графа в редакторе сценариев).
- **`ScenarioSyntaxService`** — подсветка языка сценариев для текстовых полей редакторов (редактор RPG-карт использует её для скриптов событий) и разбор строки команды на слова. Редактор интерактивов с её помощью находит, какой сценарий добавляет интерактив; редактор освещения читает и переписывает строку `light_set` через файловый сервис.

Сам язык библиотека берёт из диалогового движка (`dialog_base`). Нейтральные сервисы файлов и сцен остаются в `tools_base`, поэтому инструменты, которые не трогают сценарии, не тянут за собой диалоговый движок.

## Зависимости

`tools_base`, `dialog_base`.
